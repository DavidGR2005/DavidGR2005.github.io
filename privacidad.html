Política de privacidad de Yalgo

Última actualización: 10 de noviembre de 2026.

Yalgo es un asistente personal de uso privado. Lo usa únicamente su creador; no tiene otros usuarios.

Datos de Google que usa

  • Google Calendar (eventos): para leer la agenda y crear eventos cuando el usuario lo pide.
  • Google Tasks: para leer, crear y completar tareas cuando el usuario lo pide.

Cómo se guardan

El permiso de acceso se guarda cifrado en el equipo personal del usuario. Los datos de Calendar y Tasks no se venden, no se comparten con terceros y no se usan para publicidad. Solo se envían al modelo de IA que el asistente usa para responder, en el momento en que el usuario lo pide.

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo quitar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
